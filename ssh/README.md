# Расширенная настройка SSH

Организация работы SSH-сервера, настройка безопасного доступа и вход по ключу.

## Что внутри

Настройка SSH-сервера (`openssh-server`) на первой виртуальной машине (server) и подключение к нему со второй (server2).

- смена стандартного порта (22 → 2222);
- запрет входа от имени суперпользователя (root);
- настройка входа по SSH-ключам (без пароля);
- отключение входа по паролю.

## Шаги выполнения

1. Установка SSH-сервера: `sudo apt install openssh-server`.
2. Добавление в автозагрузку: `sudo systemctl enable sshd`.
3. Настройка безопасности в `/etc/ssh/sshd_config`:
   - Смена порта на 2222;
   - `PermitRootLogin no`;
   - `PasswordAuthentication no`.
4. Открытие порта в брандмауэре: `sudo ufw allow 2222`.
5. Перезапуск сервера: `sudo systemctl restart sshd`.
6. Генерация ключей на клиенте (server2): `ssh-keygen`.
7. Копирование ключа на сервер: `ssh-copy-id -p 2222 user@192.168.56.2`.

## Проверка

1. Подключение к серверу по новому порту: 
   `ssh -p 2222 user@192.168.56.2` (должно пройти без ввода пароля после настройки ключей).
2. Проверка прослушивания порта: 
   `sudo ss -tulnp | grep ssh` (должен быть порт 2222).
3. Попытка входа под root (должна быть отклонена).

## Конфигурация SSH

В файле `/etc/ssh/sshd_config` были изменены следующие параметры:

- `Port 2222` - смена стандартного порта;
- `PermitRootLogin no` - запрет входа под root;
- `PasswordAuthentication no` - запрет входа по паролю (только по ключу).

Полный фрагмент измененных строк находится в [configs/sshd_config](configs/sshd_config).

## Стек

- **Ubuntu Server 25.04** (VirtualBox);
- **Удалённый доступ:** `openssh-server`, `openssh-client`.

# Работа с файловым сервером Samba

Организация работы файлового сервера Samba и удаленного доступа к предоставляемым им файлам.

## Что внутри

Настройка файлового сервера (`samba`) на первой виртуальной машине (server) и доступ к общим папкам со второй (server2) с разграничением прав.

- настройка гостевого доступа (read-only и read-write);
- создание пользователей Samba и разграничение прав доступа к папкам;
- привязка символьного имени сервера через DNS.

## Шаги выполнения

1. Установка Samba: `sudo apt-get install samba`.
2. Создание каталогов для общих папок и настройка прав (`chmod 777`).
3. Редактирование конфигурационного файла `/etc/samba/smb.conf` (добавление секций `[share]`, `[readShare]`, `[user1]`, `[user2]`).
4. Создание системных пользователей и добавление их в Samba:
   - `useradd -M -s /usr/sbin/nologin user1`
   - `smbpasswd -a user1`
5. Перезапуск сервера: `sudo systemctl restart smbd`.
6. Настройка DNS для доступа по имени (добавление зоны в `bind9`).

## Проверка

1. **Гостевой доступ:** 
   `smbclient //192.168.56.2/share -N` → команда `put file.txt` (должна пройти успешно).
2. **Доступ только для чтения:** 
   `smbclient //192.168.56.2/readShare -N` → команда `put file.txt` (должна вернуть `NT_STATUS_ACCESS_DENIED`).
3. **Разграничение прав:** 
   - вход от `user1` в папку `user1`: `smbclient //share.example.org/user1 -U user1` (успешно).
   - вход от `user2` в папку `user1`: (должен вернуть `NT_STATUS_ACCESS_DENIED`).
   - вход от `user1` в папку `user2`: (чтение разрешено, запись запрещена).

## Конфигурация

В файле `/etc/samba/smb.conf` были добавлены секции:

- `[share]` - общая папка с правами на чтение и запись (гостевой доступ);
- `[readShare]` - папка только для чтения (гостевой доступ);
- `[user1]` - папка, доступная только пользователю `user1`;
- `[user2]` - папка, доступная на чтение `user1` и на запись `user2`.

Полный фрагмент добавленных строк находится в [configs/smb.conf](configs/smb.conf).

## Стек

- **Ubuntu Server 25.04** (VirtualBox);
- **Файловый сервер:** `samba`;
- **DNS:** `bind9` (для привязки имени `share.example.org`);
- **Клиент:** `smbclient`.
